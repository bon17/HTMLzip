# HTML 슬라이드 제작 원칙

이 저장소의 모든 슬라이드(덱)는 이 문서를 따른다.
목표는 한 문장이다.

> **HTML 파일 하나만 열면, 움직이는 슬라이드와 발표·필기·편집 도구가 전부 들어 있다.**

기능 등급은 세 가지로 나눈다.

- **[필수]** 모든 덱에 반드시 들어간다.
- **[권장]** 특별한 이유가 없으면 넣는다.
- **[선택]** 필요할 때만 넣는다. 외부 서버처럼 추가 조건이 있는 기능이다.

---

## 1. 핵심 원칙

1. **단일 파일**: 덱 하나는 HTML 파일 하나다. 빌드 과정 없이 더블클릭으로 열리고, 인터넷이 끊겨도 동작한다.
2. **모션이 기본**: 슬라이드 전환과 요소 등장에 모션 그래픽을 쓴다. 모션은 내용 이해를 돕기 위한 것이고, 언제든 끌 수 있어야 한다.
3. **도구 내장**: 펜, 형광펜, 레이저, 칠판, 타이머 같은 발표 도구와 편집 도구가 모든 덱에 들어간다. (§3 기능 명세)
4. **내용과 엔진 분리**: 슬라이드 내용(마크업)과 기능 코드(엔진)는 파일 안에서 구역을 나눈다. 새 덱은 공통 템플릿에서 시작한다.
5. **기록 보존**: 필기, 설정, 편집 내용은 브라우저에 자동 저장되고 되돌리기가 가능하다.
6. **어디서나 동작**: 노트북, 대형 화면, 태블릿(터치·펜)에서 모두 동작한다. 창 크기가 바뀌어도 레이아웃과 필기 위치가 어긋나지 않는다.

## 3. 기능 명세

모든 기능은 **버튼으로도, 단축키로도** 쓸 수 있어야 한다. 단축키는 모든 덱에서 같게 유지한다.

### 3.1 이동

| 기능 | 동작 | 단축키 | 등급 |
|---|---|---|---|
| 이전 / 다음 | 남은 단계(§4.1 `data-step`)가 있으면 단계를 먼저 진행하고, 없으면 슬라이드를 넘긴다. | `←` `→` / `Space` / `PageUp` `PageDown` | 필수 |
| 처음 / 끝 | 첫 슬라이드, 마지막 슬라이드로 이동 | `Home` / `End` | 필수 |
| 번호로 이동 | 숫자를 입력한 뒤 Enter | 숫자 + `Enter` | 권장 |
| 목차 | 슬라이드 제목 목록. 클릭하면 이동한다. | `O` | 필수 |
| 썸네일 패널 | 좌측 핸들로 열고 닫는다. 현재 슬라이드를 강조 표시한다. | — | 권장 |
| 스와이프 | 터치 화면에서 좌우로 밀어 넘긴다. 손 도구일 때만 동작한다. | — | 필수 |
| 주소 유지 | `#5`처럼 주소로 특정 슬라이드를 연다. 새로고침해도 위치가 유지된다. | — | 필수 |

### 3.2 필기 도구

| 기능 | 동작 | 단축키 | 등급 |
|---|---|---|---|
| 손 | 기본 상태. 클릭으로 넘기기와 링크 클릭이 가능하다. | `V` 또는 `Esc` | 필수 |
| 펜 | 자유 곡선. 선을 부드럽게 보정하고, 가능한 기기에서는 펜 압력을 반영한다. | `P` | 필수 |
| 형광펜 | 반투명한 굵은 선. 글자 위에 칠해도 글자가 보인다. | `H` | 필수 |
| 지우개 | 획 단위로 지운다(닿은 획 전체 삭제). | `E` | 필수 |
| 레이저 | 빨간 점과, 잠깐 남았다 사라지는 꼬리 | `L` | 필수 |
| 색 | 프리셋 6색과 굵기 3단계 | `C` (색 순환) | 필수 |
| 되돌리기 | 필기, 지우기, 이 장 지우기를 모두 되돌릴 수 있다. | `Ctrl/⌘ + Z` | 필수 |
| 다시 하기 | 되돌린 작업을 다시 적용한다. | `Ctrl/⌘ + Shift + Z` | 권장 |
| 이 장 지우기 | 현재 슬라이드(또는 칠판)의 필기를 전부 지운다. 되돌리기로 복구할 수 있다. | `X` | 필수 |

필기 규칙은 다음과 같다.

- 필기는 슬라이드마다 따로 저장한다. 다른 슬라이드에 갔다가 돌아와도 남아 있다.
- 좌표는 **무대 좌표(1920×1080) 기준**으로 저장한다. 그래서 창 크기를 바꾸거나 전체 화면으로 전환해도 위치가 그대로다.
- 입력은 Pointer Events 하나로 마우스, 터치, 펜을 모두 처리한다. 필기 도구 사용 중에는 스크롤과 스와이프를 막는다.
- 필기 도구를 쓰는 중에도 키보드 이동(이전/다음)은 동작한다.
- 레이어 순서는 아래부터 `슬라이드 내용 → 필기 캔버스 → 레이저 → 툴바·패널`이다.

| 요소 이동·크기 | 편집 모드에서 요소를 드래그해 위치와 크기를 조정한다. | — | 선택 |

**점검** 항목은 다음과 같다.

- 글자가 무대 밖으로 넘침
- 빈 슬라이드
- 제목(`data-title`) 없는 슬라이드
- 깨진 이미지
- 대체 텍스트(`alt`) 없는 이미지
- 알 수 없는 `data-anim` 이름

편집 모드에서는 글자 입력이 우선이다. 한 글자 단축키는 꺼지고 `Esc`(편집 종료)와 `Ctrl/⌘ + S`(저장)만 동작한다.

## 4. 모션 그래픽

### 4.1 작성 방식: 선언형

모션은 JS를 직접 쓰지 않고 **HTML 속성으로 선언**한다. 내용만 고쳐도 모션이 따라오게 하기 위해서다.

```html
<section class="slide" data-title="오늘 할 일" data-transition="fade">
  <h2 data-anim="fade-up">오늘 할 일</h2>
  <ul data-anim="stagger">
    <li data-step="1">웹앱 계획 세우기</li>
    <li data-step="2">첫 화면 만들기</li>
  </ul>
  <aside class="notes">발표자 노트: 10분 안에 끝낼 것</aside>
</section>
```

| 속성 | 위치 | 뜻 |
|---|---|---|
| `data-title` | 슬라이드 | 목차, 썸네일, 점검에 쓰이는 제목 |
| `data-transition` | 슬라이드 | 전환 효과: `fade`, `slide`, `zoom`, `none`. 생략하면 덱 기본값을 쓴다. |
| `data-anim` | 요소 | 등장 효과 이름 (아래 기본 세트) |
| `data-delay` | 요소 | 등장 지연(ms) |
| `data-duration` | 요소 | 등장 시간(ms) |
| `data-step` | 요소 | "다음"을 누를 때마다 번호 순서대로 등장한다. 없으면 슬라이드에 들어올 때 자동 재생된다. |
| `<aside class="notes">` | 슬라이드 | 발표자 노트. 발표 화면에는 보이지 않는다. |

**기본 효과 세트**

| 이름 | 효과 |
|---|---|
| `fade` | 서서히 나타남 |
| `fade-up` / `fade-down` | 아래·위에서 떠오르며 나타남 |
| `slide-left` / `slide-right` | 옆에서 밀려 들어옴 |
| `scale-in` | 작게 시작해서 커지며 나타남 |
| `blur-in` | 흐릿했다가 선명해짐 |
| `stagger` | 자식 요소들이 차례로 등장 |
| `draw` | SVG 선이 그려지듯 나타남 |
| `count-up` | 숫자가 0부터 목표값까지 올라감 |
| `typewriter` | 글자가 타자 치듯 한 글자씩 나타남 |
| `highlight` | 글자 뒤에 강조색 밑줄·배경이 그어짐 |

새 효과를 추가하면 이 표에도 추가한다.

### 4.2 동작 규칙

- **앞으로 갈 때만 재생한다.** 뒤로 돌아가면 그 슬라이드는 모든 단계가 끝난 상태로 보여 준다.
- **시간과 이징 기본값**
  - 슬라이드 전환: 300–600ms
  - 요소 등장: 400–800ms
  - 차례 등장 간격: 60–120ms
  - 이징: `cubic-bezier(0.2, 0.8, 0.2, 1)`
- **부드럽게**: `transform`과 `opacity`만 애니메이션한다(필요하면 `filter`, SVG `stroke-dashoffset`도 쓴다). `width`, `top`, `left`처럼 레이아웃을 다시 계산하게 만드는 속성은 애니메이션하지 않는다.
- **끌 수 있게**: `prefers-reduced-motion`을 존중한다. 설정에서 모션을 끄면 모든 요소가 즉시 최종 상태로 보인다.
- **반복 애니메이션은 장식에만**: 무한 반복 애니메이션은 배경 장식에만 쓰고, 읽어야 하는 내용에는 쓰지 않는다.
- **내용은 항상 보이게**: 등장 전 숨김 상태는 엔진이 붙인 클래스(예: `.motion-ready`)로만 적용한다. JS가 실패하거나 모션이 꺼져도 내용은 모두 보여야 한다.
- **인쇄·PDF**: 모든 단계를 펼친 상태로, 한 슬라이드를 한 페이지에 출력한다. 툴바는 숨긴다.

## 5. 디자인 기본값

- 비율은 16:9, 무대 크기는 1920×1080이다.
- **기본 테마(다크)**: 차콜 배경, 흰색 제목, 회색 본문, 오렌지 강조색. 설정에서 바꿀 수 있다.
- **색은 CSS 변수로만** 지정한다(`--bg`, `--surface`, `--fg`, `--muted`, `--accent` 등). 테마 전환은 변수 값을 바꾸는 것으로 끝나야 한다.
- **폰트**: Pretendard(CDN). 불러오지 못하면 `"Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif` 순서로 대체한다.
- **글자 크기 하한**: 무대 기준 본문 28px 이상. 강의실 뒷자리에서도 읽혀야 한다.
- **표지 슬라이드 구성**: 강조색 시리즈명(`— 시리즈명`) → 큰 제목 → 강조색 일시 → 회색 부가 정보(발표자 등) → 오른쪽 대표 이미지
- **툴바 스타일**: 인라인 SVG 아이콘 위에 한글 라벨을 붙인다. 둥근 모서리를 쓰고, 활성 상태는 강조색 배경으로 표시한다.
- **이미지**: 사용 권한이 있는 이미지만 쓴다.

## 6. 파일과 코드 구조

```
template/
  deck.html            # 공통 엔진이 들어 있는 기본 템플릿 (새 덱의 출발점)
decks/
  2026-11-10-basic-lecture-01.html      # 일반적인 덱 (단일 파일)
  2026-11-17-big-media-deck/            # 용량이 큰 덱만 폴더로 분리
    index.html
    assets/
```

- **파일 이름**: `YYYY-MM-DD-영문-슬러그.html`. 한글 파일 이름은 zip이나 URL에서 깨질 수 있으므로 피한다. 덱 제목은 파일 안의 `<title>`에 한글로 쓴다.
- **파일 내부 구역 순서**
  1. `<style>`: 엔진 스타일 (`/* ===== ENGINE vX.Y ===== */` 표시)
  2. `<style>`: 이 덱만의 스타일
  3. `<main id="deck">`: 슬라이드들 (`<section class="slide">`)
  4. `<script>`: 엔진 (`// ===== ENGINE vX.Y =====` 표시)
- **외부 라이브러리 없이** 바닐라 HTML/CSS/JS로 만든다. 폰트 CDN만 예외로 허용한다.
- **이미지는 파일 안에 내장**한다(SVG 인라인 또는 data URI). 파일이 대략 5MB를 넘을 때만 폴더와 `assets/`로 나누고, 폴더째 zip으로 배포한다.
- **엔진을 고치면 `template/deck.html`도 함께 고치고** 엔진 버전을 올린다.
- **브라우저 저장소 키**는 `htmlzip:<덱id>:<항목>` 형식으로 쓴다. 저장소 접근은 항상 `try/catch`로 감싼다. 사파리 개인정보 보호 모드처럼 저장이 막힌 환경에서도 덱은 정상 동작해야 한다.

## 7. 완성 체크리스트

덱을 "완성"이라고 하기 전에 아래를 모두 확인한다.

- [ ] 크롬·엣지·사파리에서 더블클릭으로 열리고 콘솔 에러가 없다
- [ ] 인터넷 없이 열어도 동작한다 (폰트만 대체됨)
- [ ] 키보드, 버튼, 스와이프로 모든 슬라이드를 이동할 수 있고 단계 순서가 맞다
- [ ] 펜, 형광펜, 지우개, 레이저, 색, 되돌리기, 이 장 지우기가 동작하고, 슬라이드를 넘겨도 필기가 남아 있다
- [ ] 창 크기를 바꾸거나 전체 화면으로 전환해도 필기 위치가 그대로다
- [ ] 칠판과 슬라이드를 오가면 보던 위치로 돌아온다
- [ ] 편집 후 저장한 파일을 다시 열면 수정 내용이 반영되어 있다
- [ ] 점검 결과가 0건이다 (또는 의도한 예외만 남아 있다)
- [ ] 모션을 끄거나 reduced-motion 환경에서도 모든 내용이 보인다
- [ ] 인쇄 미리보기에서 한 슬라이드가 한 페이지로 나온다
