# 슬라이드 이미지 만들기 (ChatGPT용 프롬프트)

## 만드는 방법

1. ChatGPT에서 **새 대화 하나**를 열고, 아래 이미지를 **그 대화 안에서 차례대로** 만들어요. 같은 대화에서 이어서 만들어야 그림체와 로봇 캐릭터가 똑같이 유지돼요.
2. 맨 처음에 **[공통 스타일]**을 한 번 보내고, 그다음부터는 각 프롬프트만 보내면 돼요.
3. 다 만든 그림은 이 대화창에 올려 주세요. 제가 파일 이름을 붙여서 `images/` 폴더에 넣을게요.
   - 직접 넣을 때는 아래 표의 **파일 이름** 그대로 `images/` 폴더에 저장하면 돼요.
4. **필수**는 꼭 필요한 그림이에요. **선택**은 없으면 발표 화면에서 아이콘으로 대신 보여요.

---

## [공통 스타일] — 맨 처음에 한 번 보내기

```
지금부터 중학생 대상 수업 슬라이드에 넣을 일러스트를 여러 장 만들 거야. 모든 그림을 아래 스타일로 통일해 줘.

- 플랫한 벡터 일러스트, 둥글고 귀여운 형태
- 굵은 남색(#1C2340) 외곽선, 그림자나 그라데이션 없이 단순하게
- 색은 주황 #FF7A1A, 파랑 #2F7BFF, 보라 #8A5CFF, 초록 #17B26A, 분홍 #FF4D8D, 노랑 #FFC21A 위주
- 배경은 투명(PNG)
- 그림 안에 글자, 숫자, 로고는 절대 넣지 말 것 (말풍선 속 글자도 기호나 물결선으로만)
- 등장하는 AI는 항상 같은 캐릭터: 하늘색 둥근 몸, 동그란 화면 얼굴에 웃는 눈, 머리 위 안테나 하나가 있는 작은 로봇
- 학생은 교복을 입은 한국 중학생, 성별이 드러나지 않게

알겠으면 "준비됐어"라고만 대답해 줘.
```
