# 슬라이드 이미지 만들기 (ChatGPT용 프롬프트)

> **그림 스타일: 차분한 파스텔 플랫** (2026-11-11 결정)
> 예전 스타일(원색 + 굵은 스티커 선)은 색이 강렬해서 촌스러워 보여 바꿨어요. 채도를 낮춘 파스텔 색과 가는 선으로, 교과서 삽화처럼 차분하고 깔끔하게 만들어요.

## 만드는 방법

1. ChatGPT에서 **새 대화 하나**를 열고, 아래 그림을 **그 대화 안에서 차례대로** 만들어요. 같은 대화에서 이어서 만들어야 색감, 선 굵기, 로봇 캐릭터가 똑같이 유지돼요.
2. 맨 처음에 **[공통 스타일]**을 한 번 보내고, 그다음부터는 각 프롬프트만 보내면 돼요.
3. 첫 그림이 마음에 들게 나오면 **[기준 그림 고정]** 문장을 한 번 보내요. 그 뒤 그림들이 첫 그림과 같은 느낌으로 나와요.
4. 색이 다시 진해지거나 선이 굵어지면 **[바로잡기]** 문장을 보내요.
5. 다 만든 그림은 이 대화창에 올려 주세요. 제가 이름을 붙여서 **덱 파일(`decks/2026-12-24-ai-prompt-class/index.html`) 안에** 넣을게요. 원칙상 그림은 파일 안에 넣어요(용량을 줄여서).
6. **필수**는 꼭 필요한 그림이에요. **선택**은 없으면 지금처럼 선 아이콘이 대신 보여요.

## [공통 스타일] — 맨 처음에 한 번 보내기

```
지금부터 중학생 대상 수업 슬라이드에 넣을 일러스트를 여러 장 만들 거야. 모든 그림을 아래 스타일로 통일해 줘.

- 차분한 플랫 일러스트. 교과서 삽화처럼 깔끔하고 단순하게, 둥글고 귀여운 형태
- 선: 가늘고 부드러운 진남색(#2B3150) 선, 굵기는 일정하게. 굵은 스티커 외곽선은 쓰지 말 것
- 색: 채도를 낮춘 파스텔 톤만 써 줘
  살구 #F2B48C, 하늘 #A9C8E8, 라벤더 #BEB0E3, 세이지 그린 #A8CDB3, 로즈 #EDB3BF, 버터 #F3D899, 민트 #A6D8D2
  면은 크림색(#FFF8EE)이나 흰색을 넉넉히 섞어서 밝고 가볍게
- 형광색, 원색(빨강·파랑·노랑을 진하게), 진한 그라데이션, 광택, 3D 느낌, 진한 그림자는 쓰지 말 것. 명암은 아주 옅게 한 단계만
- 한 그림에 색은 3~4가지만, 사물은 꼭 필요한 것만 넣고 여백을 넉넉하게
- 배경은 투명(PNG)
- 그림 안에 글자, 숫자, 로고는 절대 넣지 말 것 (말풍선 속 글자도 점이나 물결선으로만)
- 등장하는 AI는 항상 같은 캐릭터: 연한 하늘색 둥근 몸, 흰색 동그란 화면 얼굴에 남색으로 그린 웃는 눈, 머리 위 안테나 하나(끝에 살구색 동그라미)가 있는 작은 로봇
- 학생은 차분한 남색 교복을 입은 한국 중학생, 성별이 드러나지 않게, 얼굴은 단순하게

알겠으면 "준비됐어"라고만 대답해 줘.
```

## [기준 그림 고정] — 첫 그림이 마음에 들면 한 번 보내기

```
좋아. 앞으로 만드는 그림은 모두 방금 그림과 같은 색감, 같은 선 굵기, 같은 로봇 캐릭터로 그려 줘.
```

## [바로잡기] — 색이 진해지거나 선이 굵어졌을 때

```
방금 그림은 색이 너무 진해. 공통 스타일대로 채도를 낮춘 파스텔 톤과 가는 남색 선으로 다시 그려 줘. 형광색, 원색, 굵은 외곽선, 진한 그림자는 빼 줘. 내용과 구도는 그대로 둬.
```
