# 수업 설계 — AI 잘 쓰면, 나도 잘 된다! (중2)

## 수업 조건

| 항목 | 내용 |
|---|---|
| 대상 | 중2 약 150명 (1~5반, 반당 약 30명), 한 공간에서 동시에 |
| 시간 | 2차시(90분) 기준 |
| 학생 기기 | 구형 갤럭시탭 (화면 분할 사용 못 함) |
| 학생 AI | 학교 구글 계정으로 로그인한 제미나이 |
| 핵심 메시지 | “좋은 프롬프트를 쓰려면 내가 먼저 생각해야 한다” · ‘써줘’ 말고 재료를 넣으면 결과가 달라진다 |
| 톤 | 훈계하지 않기. “AI 쓰지 마”가 아니라 “제대로 시키면 결과가 이렇게 다르다”를 비교로 체감 |

## 전체 흐름

| 차시 | 내용 |
|---|---|
| 1교시 | 도입부(약 18분) → 미션 1 몽타주(15분) → 미션 2 세계관 요리(12분) |
| 2교시 | 미션 3 역할(8분) → 미션 4 시험공부(10분) → 미션 5 진로(10분) → 미션 6 진짜 숙제(12분) → 마무리(5분) |

## 도입부 (완성, 17장)

1. 표지
2. 오늘의 질문 — 학습지 사진 + “써줘” 채팅, “해 본 사람 손!”
3. PART 1 챕터 화면 — AI는 어떤 친구일까?
4. AI는 검색 기계가 아니에요 (검색 = 찾기 / 생성 = 만들기)
5. 자동완성 체험 (태블릿 키보드 추천 단어 30초)
6. 그럴듯하다고 사실은 아니에요
7. 영상: 챗GPT의 아무말 대잔치 (맥북 던짐 사건, 1분 15초)
8. 할루시네이션 — AI의 당당한 거짓말
9. 안 속는 법 3가지 + 보너스 재료 ‘안전장치’ 획득
10. PART 2 챕터 화면 — 프롬프트가 뭘까?
11. 프롬프트란? (prompt = 대사를 일러 주다, 프롬프터)
12. 영상: 전과자 컴퓨터공학과 (사람을 컴퓨터처럼 시키기, 33초)
13. 왜 처음엔 실패했을까? (“숟가락 집어서 먹어” vs 하나하나 자세히)
14. AI도 똑같아요 — 맥락을 모르면 엉뚱한 답 (‘평균적인 답’이라는 표현은 쓰지 않기)
15. 같은 AI, 다른 결과 (고양이 그림 2장)
16. 오늘 모을 재료 6개 + 보너스
17. 미션 진행 방법 (1차 한 줄 → 2차 재료 → 비교, QR·입장 코드)

## 미션 공통 틀

1. **1차:** 한 줄짜리 프롬프트로 결과 받기 → Before에 올리기
2. **2차:** 재료를 하나 더 넣어서 다시 받기 → After에 올리기
3. **비교:** 큰 화면에서 Before / After 나란히 (반별 탭, 학생별 짝 보기)

학생들은 새로 지어내기를 어려워해요. 그래서 **모든 재료는 보기(약 10개)에서 골라 조합**하고, 학생 태블릿의 조합기가 문장을 자동으로 완성해 줘요. 제미나이 학생 계정 거절을 피하려고 사람 얼굴, 실존 인물, 무서운 내용, 유명 캐릭터는 보기에서 뺐어요.

## 미션별 메뉴

### 미션 1. 몽타주 (재료: 디테일) — 이미지
- 1차: “[주인공] 그려줘” (2차와 같은 주인공)
- 조립: “[그림체]로, [옷차림]을 한 [주인공]이 [장소]에서 [행동·표정] 모습을 [분위기]로 그려줘.”

| 재료 | 보기 |
|---|---|
| 주인공 | 고양이 / 강아지 / 펭귄 / 햄스터 / 공룡 / 로봇 / 토끼 / 북극곰 / 판다 / 수달 |
| 옷차림·소품 | 교복 / 우주복 / 요리사 모자 / 헤드폰 / 노란 우비 / 왕관 / 안경과 책가방 / 축구 유니폼 / 마법사 망토 / 한복 |
| 장소 | 학교 매점 / 우주 정거장 / 바닷속 / 도서관 / 비 오는 편의점 앞 / 놀이공원 / 눈 덮인 산꼭대기 / 교실 맨 뒷자리 / 떡볶이 가게 / 무대 위 |
| 행동·표정 | 마지막 남은 빵을 보고 놀란 / 시험지를 보고 좌절한 / 신나게 춤추는 / 졸려서 하품하는 / 컵라면 먹으며 행복한 / 친구와 하이파이브하는 / 몰래 간식 먹다 들킨 / 노래 부르는 / 셀카 찍는 / 숙제하다 머리 싸맨 |
| 그림체 | 웹툰 / 픽셀 아트 / 수채화 / 클레이 애니메이션 / 스티커 / 3D 애니메이션 / 동화책 삽화 / 레고 블록 / 크레파스 그림 / 따뜻한 애니메이션 |
| 분위기 | 밝고 알록달록한 / 노을빛 / 밤하늘과 반짝이는 불빛 / 파스텔 톤 / 흑백 |

- 수정 프롬프트: 배경을 밤으로 바꿔 줘 / 표정을 더 웃기게 / 옆에 친구 한 마리 추가해 줘 / 그림체를 픽셀 아트로 / 소품 하나 더 들려 줘
- 막혔을 때 카드: 사람 → 동물로 / ‘사실적인’ → ‘귀여운 일러스트’로 / 무서운 단어 빼기 / 캐릭터 이름 대신 생김새로 설명

### 미션 2. 세계관 요리 (재료: 상황) — 글
- 1차: “[음식] 만드는 법 알려줘”
- 조립: “나는 [세계관]에 있어. 가진 건 [가진 것]뿐이야. [제약]. [음식] 만드는 법 알려줘.”

| 재료 | 보기 |
|---|---|
| 음식 | 라면 / 김밥 / 떡볶이 / 주먹밥 / 토스트 / 샌드위치 / 계란후라이 / 팬케이크 / 과일 화채 / 핫초코 |
| 세계관 | 무인도에 표류 / 우주 정거장 / 조선시대 수라간 / 정전된 우리 집 / 캠핑장 / 시험 기간 새벽 1시 내 방 / 100년 뒤 미래 도시 / 남극 기지 / 수학여행 숙소 / 해적선 |
| 가진 것 | 전자레인지만 / 불 없이 / 냄비 하나 / 편의점 재료만 / 물 500ml / 숟가락 하나 / 재료 3개 |
| 제약 | 10분 안에 / 소리 내면 안 됨 / 5,000원 이하 / 3명이 나눠 먹기 / 설거지 없이 / 그 시대에 있던 재료만 |

### 미션 3. 누가 설명해 줄래? (재료: 역할) — 글
- 1차: “[개념] 설명해 줘”
- 조립: “너는 [역할]이야. [듣는 사람]에게 [개념]을 설명해 줘.”

| 재료 | 보기 |
|---|---|
| 개념 (세계사) | 4대 문명의 탄생 / 아테네의 민주 정치 / 진시황의 중국 통일 / 칭기즈 칸과 몽골 제국 / 신항로 개척 |
| 개념 (한국사) | 고조선의 건국 / 광개토 대왕의 영토 확장 / 신라의 삼국 통일 / 세종의 훈민정음 창제 / 이순신과 임진왜란 |
| 역할 | 축구 해설위원 / 아이돌 리더(팬들에게 메시지) / 래퍼(8마디 랩) / 유치원 선생님 / 게임 속 NPC / 요리 유튜버 / 기상 캐스터 / 홈쇼핑 쇼호스트 / 조선시대 선비 / 탐정 |
| 듣는 사람 (선택) | 초등학교 2학년 동생 / 시험 전날 벼락치기하는 중2 / 지구에 처음 온 외계인 / 우리 할머니 |

- 대안 역할(제안만 함): 기상 캐스터·요리 유튜버 → “그 시대 뉴스 앵커(속보)”, “타임머신 여행 가이드”

### 미션 4. 시험공부 (재료: 모양) — 글
- 1차: “[주제] 정리해 줘”
- 조립: “[주제]를 중2 수준으로 [모양]으로 정리해 줘. [안전장치]”

| 재료 | 보기 |
|---|---|
| 주제 | 광합성 / 소화 과정 / 전류와 전압 / 별의 밝기 / 일차함수 / 확률 / 연립방정식 / 기후 변화 / 민주주의 / 비유법 / 직접 쓰기 |
| 모양 | 핵심 5개 표 / 3줄 요약 / OX 퀴즈 5개 / 객관식 3문제와 해설 / 헷갈리는 개념 비교표 / 카톡 단톡방 대화 / 4컷 만화 대본 / 쉬운 비유 3개 / 시험 전날 10분 체크리스트 / 동요 가락에 맞춘 암기송 |
| 안전장치 (기본 체크) | “확실하지 않은 내용은 ‘확인 필요’라고 표시해 줘” |

### 미션 5. 진로 (재료: 질문받기) — 대화
- 1차: “나한테 맞는 진로 추천해 줘”
- 조립: “나는 중2인데 진로를 아직 모르겠어. 나한테 [질문 방식]으로 질문을 [개수] 해서 내 [알아볼 것]을 파악해 줘. 다 묻고 나면 [결과 모양]으로 추천해 줘.”

| 재료 | 보기 |
|---|---|
| 질문 방식 | 한 번에 하나씩 / 밸런스 게임처럼 (A vs B) / 보기 3개 객관식 / 짧게 한 줄로 |
| 개수 | 3개 / 5개 / 7개 |
| 알아볼 것 | 좋아하는 것 / 잘하는 것 / 싫어하는 것 / 쉬는 날 하는 것 / 칭찬받은 경험 |
| 결과 모양 | 직업 3개와 이유 / 그 직업의 하루 일과 / 지금 해 볼 수 있는 활동 1개씩 / 관련 있는 과목 |

### 미션 6. 진짜 숙제 (재료: 전부 + 내 이야기) — 글
- 1차: “[과제] 써줘”
- 조립: 역할 → 상황 → 내 이야기 → 할 일 → 모양 → 안전장치 순서로 이어 붙이기

| 재료 | 보기 |
|---|---|
| 과제 | 나를 소개하는 글 / 나에게 특별한 물건 / 내가 좋아하는 계절 / 최근 본 영화·책 감상 / 우리 학교 자랑 / 바꾸고 싶은 학교 규칙 / 나의 인생 음식 / 10년 뒤 나에게 쓰는 편지 |
| 역할 | 국어 선생님 / 글쓰기 코치 / 친한 선배 / 출판사 편집자 / 라디오 DJ |
| 상황 | 쓰는 곳: 발표 / 학급 신문 / 수행평가 / 블로그 · 분량: 200자 / 300자 / 500자 |
| 할 일 | 내 이야기로 초안 써 줘 / 질문으로 내 이야기 더 끌어내 줘 / 첫 문장 아이디어 3개만 / 개요만 짜 줘 |
| 모양 | 문단 3개 / 개요표 / 중2 말투로 |
| 내 이야기 | 빈칸 채우기: “그건 ___ 때였어”, “그때 나는 ___ 기분이었어”, “가장 기억나는 장면은 ___” |
| 안전장치 (기본 체크) | “내가 말하지 않은 경험은 지어내지 마” |

- 마지막 비교 질문: “둘 중에 내 이름으로 낼 수 있는 건 어느 쪽이야?”

## 마무리
- 프롬프트 레시피 한 장 정리 (재료 6개 + 보너스)
- “써줘” 대신 이렇게: 써줘 → 나한테 질문해 줘 / 풀어줘 → 힌트만 줘 / 정리해 줘 → 표랑 퀴즈로 만들어 줘
- 픽셀 퀴즈 (원본 고등학생 자료 형식): 재료 3개 말하기, “고양이 그려줘” 업그레이드, 역질문 프롬프트 만들기
- 슬로건: AI 잘 쓰면, 나도 잘 된다

## 실시간 제출·투표 (3단계 설계)

- **방식:** 구글 시트 + Apps Script 웹 앱. 선생님 **개인 Gmail**로 배포 (학교·기관 계정은 ‘누구나 접근’이 막힐 수 있음)
- **로그인:** 선생님과 학생 계정 도메인이 달라서 로그인 없이 받아요. 반·번호 + 슬라이드에 뜨는 **4자리 입장 코드** + 기기당 1표
- **학생 화면:** 입장 코드·반·번호 입력(한 번) → 슬라이드가 지금 미션을 알려 주면 자동 전환 → 보기 고르기 → 프롬프트 자동 완성 → [복사] (안 되는 기기는 길게 눌러 복사) → 제미나이 → 결과 올리기 (이미지 미션은 캡처, 글 미션은 답변 복사)
- **슬라이드 화면:** 몇 초마다 새 결과 확인 → 카드 애니메이션. 반 탭(1~5반, 전체 = 150장 모자이크), 학생별 Before→After 짝 보기, 장난 제출 숨기기
- **투표:** 원하는 미션에서만 열기(1~2개 추천). 자기 반 안에서만, 자기 작품 제외. 반별 1등 5개 → 반 대표 대결(전체 투표)
- **150명 동시 대비:** Apps Script는 한 번에 약 30개 요청 → 자동 재시도, 몰리면 “1반부터 올리자” 반별 순서. 사진은 기기에서 약 100KB로 줄이기, 투표용 작은 미리보기 따로 만들기
- **호환:** 학생 페이지는 구형 갤럭시탭 크롬·삼성 인터넷용으로 가볍게 (최신 문법 쓰지 않기)
- **QR:** 오래된 기종은 QR 인식이 없을 수 있어 짧은 주소도 함께 표시
- **개인정보:** 이름 없이 반·번호만. 수업 후 초기화와 드라이브 폴더 삭제
- **리허설:** 강의 전에 여러 기기로 동시 제출 테스트
