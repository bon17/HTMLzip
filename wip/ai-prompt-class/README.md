# AI 잘 쓰면, 나도 잘 된다! — 중2 프롬프트 특강 슬라이드 (작업 중)

중학교 2학년 대상 프롬프트 교육 특강에 쓰는 **HTML 슬라이드**예요. 발표, 편집, 타이머, 랜덤 뽑기, 판서 기능이 하나의 파일 안에 들어 있어요.

> **작업 중인 폴더예요.** HTMLzip 제작 원칙(`docs/PRINCIPLES.md`)에 맞춰 `decks/`로 옮길 예정이에요. 자세한 내용은 이 폴더의 `CLAUDE.md`에 있어요.

## 수업에서 쓰기

1. HTMLzip 저장소를 내려받고 `wip/ai-prompt-class` 폴더를 열어요. GitHub의 **Code → Download ZIP** 또는 `git clone`
2. 영상 파일 2개를 같은 폴더에 넣어요. 저작권 때문에 저장소에는 없어요.
   - `영상1_맥북던짐사건.mp4`
   - `영상2_전과자.mp4`
3. `AI프롬프트특강_슬라이드.html`을 더블클릭해서 크롬이나 엣지로 열어요.
4. **?** 키를 누르면 단축키 전체가 나와요.

> 글꼴(주아, 나눔고딕)은 인터넷에서 불러와요. 인터넷이 안 되면 맑은 고딕으로 보여요.

## 고치기

- **간단한 수정:** 슬라이드에서 **E** 키를 눌러 편집 모드로 들어가요. 편집 내용은 그 컴퓨터 브라우저에 자동 저장돼요. 다른 컴퓨터로 옮길 때는 **HTML로 내보내기**를 쓰세요.
- **내용을 크게 바꿀 때:** `src/deck.js`를 고친 뒤 `node build.js`로 다시 만들어요.
