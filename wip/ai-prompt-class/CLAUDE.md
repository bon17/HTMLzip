# AI 프롬프트 특강 (중2) — 작업 안내

김보은 선생님(기산중)의 중2 대상 특강 “AI 잘 쓰면, 나도 잘 된다!”에 쓰는 **HTML 슬라이드**와, 앞으로 만들 **학생 제출 페이지**예요. 상동고 고등학생 특강(2026.7.1) 자료를 중2 눈높이로 다시 만든 거예요.
수업 조건, 흐름, 미션 메뉴는 [docs/수업_설계.md](docs/수업_설계.md)에 모두 정리돼 있어요. 작업 전에 먼저 읽어 주세요.

## 지금 상태: HTMLzip 원칙에 맞추기 전의 작업본

이 폴더는 HTMLzip 저장소 원칙([../../docs/PRINCIPLES.md](../../docs/PRINCIPLES.md))이 생기기 전에 따로 만든 작업본이에요. 그래서 **원칙과 다른 점이 있어요.** 선생님은 이 작업본을 원칙에 맞게 옮긴 다음 이어서 작업하기로 하셨어요.

**다음에 할 일: 원칙에 맞춰 옮기기**
1. 원칙대로 공통 엔진(`engine/engine.css`, `engine/engine.js`)을 만들어요. 이 폴더 `src/engine.js`에서 잘 되는 부분은 살려서 가져가요.
   - 챕터 전환 모션, 재료 카드(잠금 해제), 채팅 위젯, 자동완성 위젯
   - 랜덤 뽑기, 발표자 화면, 내보내기
2. 이 강의를 `decks/YYYY-MM-DD-영문-슬러그/index.html` 덱으로 옮겨요. 영상이 있어서 폴더형 덱이 돼요.
   - 영상은 `assets/`에 두고 저장소에는 올리지 않아요.
   - 그림은 원칙대로 파일 안에 넣거나 `assets/`에 둬요.
3. 옮긴 뒤에 2단계(미션 슬라이드)와 3단계(제출·투표)를 진행해요.
4. 다 옮기면 이 `wip/ai-prompt-class` 폴더는 선생님께 여쭤본 뒤 정리해요.

**원칙과 다른 점 (옮길 때 원칙 쪽으로 맞추기)**
- **구조:** 지금은 자체 엔진 + JSON 덱 + `node build.js` 빌드예요. 원칙은 `engine/` 공통 엔진을 덱 파일에 그대로 넣고, 슬라이드는 선언형 HTML(`<section class="slide">`, `data-anim`, `data-step`)로 써요.
- **단축키**
  - 지금 G = 전체 보기 → 원칙 G = 축하 효과
  - 지금 E = 편집 → 원칙 E = 지우개, 편집은 Shift+E
  - 지금 B·W = 화면 가리기 → 원칙 B = 칠판
  - 지금 A = 툴바 숨기기 → 원칙은 전체 화면에서 자동으로 숨김
- **없는 필수 기능**
  - 칠판, 지우개(획·부분), 목차(O), 축하 효과
  - 점검, 모션 강도 설정, 왼쪽 썸네일 패널, 주소 유지(#5), 파일에 직접 저장
  - 상단 진행 바, 좌하단 페이지 번호
- **파일:** 원칙은 영문 파일 이름에 그림을 파일 안에 넣어요. 지금은 한글 파일 이름에 `images/` 폴더를 써요. 저장소 키도 원칙은 `htmlzip:<deck-id>:<항목>`이에요.
- **원칙과 겹칠 때:** 아래 ‘선생님 피드백’은 이 강의에 대한 선생님의 직접 요청이에요. 원칙과 부딪히면 임의로 고르지 말고 선생님께 여쭤봐요.
  - 예: 원칙 §3.6의 ‘이모지·아이콘 추가’는 권장 기능이지만, 이 강의 슬라이드에는 이모지를 쓰지 않아요.

## 빌드와 확인

- `node build.js` → `AI프롬프트특강_슬라이드.html` 하나가 만들어져요. 외부 라이브러리 없이 Node만 있으면 돼요.
- 소스: `src/template.html`(뼈대) · `src/style.css` · `src/icons.js`(선 아이콘) · `src/engine.js`(발표·편집 엔진) · `src/deck.js`(슬라이드 내용)
- 미리 보기: 이 폴더에서 `python -m http.server 8765` 실행 후 브라우저로 열기. 실제 수업에서는 HTML 파일을 더블클릭해서 열어요(file://).
- 브라우저에 자동 저장된 편집본이 있으면, 새로 빌드한 파일을 열 때 선택 창이 떠요. 새 내용을 보려면 **‘이 파일 내용으로 시작’**을 고르세요.
- 영상 2개(`영상1_맥북던짐사건.mp4`, `영상2_전과자.mp4`)는 저작권과 용량 때문에 저장소에 없어요. HTML과 같은 폴더에 따로 복사해야 재생돼요.
- 그림은 `images/` 폴더의 파일을 불러와요. 파일 이름과 ChatGPT 프롬프트는 [docs/이미지_프롬프트.md](docs/이미지_프롬프트.md)에 있어요.

## 선생님 피드백 — 반드시 지킬 것

- **이모지 금지.** AI 느낌이 난다고 싫어하셨어요. 슬라이드 그림은 `images/` 일러스트로, 작은 아이콘은 `src/icons.js`의 선 아이콘(`icoSvg`)으로 넣어요.
- **글꼴:** 제목·강조·버튼은 주아(Jua, `style.font: 'fun'`), 본문은 나눔고딕. 주아는 굵기가 하나뿐이라 `fw: 400`으로 둬요.
- **가독성 최우선:** 강당에서 150명이 봐요. 1920×1080 기준 본문 44px 이상, 핵심 문구는 더 크게, 회색 글씨와 긴 문장은 피해요. 빈 여백도 남기지 않아요.
- **모션:** 챕터가 넘어갈 때는 ‘우와’ 소리가 나오는 모션 그래픽(`chapter` 위젯)을 써요. 제목은 `anim: 'letters'`.
- **슬라이드 안에 효과음은 넣지 않아요.** 소리는 타이머와 랜덤 뽑기에만 있어요.
- **훈계조 금지.** “AI 쓰지 마”가 아니라 “재료를 넣어 제대로 시키면 결과가 달라진다”를 비교로 느끼게 해요.
- **“평균적인 답”이라는 표현은 쓰지 않아요.** 학생들이 “평균이면 되지”라고 받아들일 수 있어서 “맥락을 모르면 엉뚱한 답, 틀린 답”으로 말해요.
- 학생들은 새로 지어내기를 어려워해요. 미션 재료는 보기(약 10개)에서 고르게 해요.
- 큰 방향을 바꾸기 전에는 먼저 구성안을 보여 주고 확인받아요. 선생님은 구상 단계에서 자주 방향을 조정하세요.

## 엔진 구조 메모 (`src/engine.js`)

- 무대는 1920×1080이에요. 요소 필드: `{ id, type, x, y, w, h, style, step, steps, anim, delay, rot, z, opacity }`
- `step`: 몇 번째 클릭에 나타나는지 (0이면 처음부터). `steps`: 위젯 안에서 쓰는 클릭 수
- 위젯: `text` · `image`(`src: 'images/...'`, 없으면 `fallback` 아이콘 또는 `optional`이면 숨김) · `video` · `chat` · `autocomplete` · `ingredients` · `chapter` · `qr`(자리표시)
- 등장 효과: fade / up / zoom / pop / left / right / letters / type / swing
- 저장: IndexedDB(`ai-prompt-class`, 키 `save:<docId>`)에 자동 저장. 덱 `rev`가 다르면 선택 창이 떠요.
- 내보내기: 처음 불러온 HTML(PRISTINE)에서 `deck-data` 부분만 바꿔서 새 파일로 내려받아요.
- 발표 기능: 숫자+Enter 이동, F 전체화면, G 전체 보기, B/W 화면 가리기, T 타이머, R 랜덤 뽑기, P/H/L 펜·형광펜·레이저, S 발표자 화면, A 툴바 숨기기, E 편집, F5/Shift+F5

## 남은 일

0. **HTMLzip 원칙에 맞춰 옮기기** (위 ‘다음에 할 일’ 참고, 미션보다 먼저)
1. **2단계 — 미션 슬라이드 + 결과 보드**
   - 미션 1~6마다 챕터 화면, 1차/2차 예시, 비교 화면을 만들어요.
   - 재료 카드는 미션이 끝날 때마다 하나씩 열려요(`ingredients`의 `unlock`).
   - Before/After 보드에는 반 탭(1~5반, 전체), 학생별 짝 보기, Ctrl+V 붙여넣기가 들어가요.
   - 마무리 슬라이드: 레시피, “써줘 대신”, 픽셀 퀴즈, 슬로건
   - 미션별 이미지 프롬프트도 추가로 드려야 해요.
2. **3단계 — 실시간 제출·투표:** 구글 시트 + Apps Script, 학생용 프롬프트 조합기 페이지. 설계는 docs/수업_설계.md 끝부분에 있어요.
3. 선생님이 그림을 올려 주시면 `images/`에 파일 이름대로 저장해요.
