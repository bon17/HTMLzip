1 · 움직이는 수업 슬라이드

교과서 PDF로 움직이는 수업 슬라이드 만들기

교과서 PDF와 기능 파일을 AI에게 올리고 시작 글 하나만 붙여 넣으면 돼요. 디자인과 화면 구성은 AI가 제안하고, 선생님은 짧게 답하며 고르기만 해요. 받은 파일을 열어 고화질 사진을 넣으면 끝이에요.

  1. 준비PDF, 기능 파일, 설정 하나
  2. 시작 글 붙여 넣기교과서 이름만 바꿔요
  3. 고르고 답하기디자인 추천 → 구성 계획과 시안 → “만들어 줘”
  4. 그림 넣기받은 파일의 창에 고화질 사진을 끌어다 놓아요
  5. 고쳐 쓰기말로 고쳐 달라고 하거나 직접 고쳐요

0 · 준비

준비물

  • AI 설정: Claude는 왼쪽 아래 내 이름 → 설정 → 기능(Capabilities)에서 ‘파일 생성 및 편집’(예전 이름 ‘코드 실행 및 파일 생성’)이 켜져 있는지 확인해요. 대부분 처음부터 켜져 있어요(메뉴 이름은 조금 다를 수 있어요). ChatGPT는 따로 켤 것 없이 바로 돼요. AI가 기능 파일을 코드로 복사해서 HTML 파일로 돌려주려면 이 기능이 있어야 해요.
  • 교과서 PDF: 슬라이드로 바꿀 부분만 잘라서 올리세요. 전체를 올리는 것보다 정확해요.
  • 기능 파일 slide-engine.html: 아래 버튼으로 내려받아요.
  • 고화질 사진(있으면): 교과서 그림의 고화질 파일, 직접 찍은 사진. AI에게 올리지 않아요. 다 만든 파일을 열고 ‘그림 넣기’ 창에 넣어요(3단계).
slide-engine.html · 약 320KB

기능 파일에는 발표·필기·편집 기능(엔진)과, AI가 읽는 작성 안내가 들어 있어요. 디자인 틀이 아니에요. 슬라이드의 모양과 배치는 AI가 수업 내용에 맞게 새로 만들어요. 회색 기능 시연 11장이 들어 있어서, 그냥 열어 봐도 어떤 움직임과 학생 참여 활동을 쓸 수 있는지 볼 수 있어요.

1단계

시작 글 붙여 넣기

새 대화에 교과서 PDF와 기능 파일을 함께 올리고 아래 글을 붙여 넣어요. 바꿀 곳은 [교과서 이름] 하나예요. ‘추가 사항’은 해당하는 것만 남기고 지워도 돼요.

시작 글
첨부한 PDF는 [중학교 2학년 역사] 교과서예요. 이 내용을 움직이는 수업 슬라이드로 바꾸려고 해요.
함께 올린 slide-engine.html은 발표·필기·편집 기능이 든 기능 파일이에요. 디자인 틀이 아니에요.
파일 맨 위 '작성 안내'를 먼저 읽고, 디자인과 화면 구성은 이 내용에 맞게 최대한 다양하고 멋지게 제안해 주세요.

■ 추가 사항 (해당하는 것만 남기고 지워도 돼요)
- 화면: 선생님 노트북을 교실 TV·빔프로젝터에 연결해서 띄워요. 넘기기와 퀴즈는 키보드·마우스로 해요.
  (다른 경우: 강당 대형 화면 / 선생님이 태블릿을 TV에 연결해서 태블릿으로 작동 / 학생이 각자 태블릿으로 봄)
- 슬라이드 수: 제한 없어요. 내용에 맞게 정해 주세요. (꼭 필요할 때만 예: 20장 이내)
- 꼭 넣을 것: (없으면 지우기. 예: 사료 읽기, 확인 문제 3개)

■ 이렇게 진행해 주세요. 단계마다 제 답을 기다려 주세요.
1단계 · 디자인 추천
- PDF를 읽고 이 단원에 어울리는 디자인 콘셉트 3가지를 제안하고, 가장 좋은 하나를 추천해 주세요.
- 콘셉트마다: 이름과 한 줄 설명(이 화면이 무엇처럼 보이는지), 배치와 장식, 색과 글꼴(학교안심 글꼴 먼저), 어울리는 이유
2단계 · 구성 계획과 시안 (제가 콘셉트를 고르면)
- 슬라이드 표: 번호 | 제목 | 화면 문구 | 화면 구성(이 장의 주인공과 배치) | 움직임 | 학생 활동 | 교과서 쪽
- 표지와 대표 장 2장(설명 장, 학생 참여 장)을 시안 파일로 만들어 보여 주세요.
3단계 · 전체 만들기 (제가 "만들어 줘"라고 하면)
- 모든 슬라이드를 HTML 파일 하나로 주세요.
- 사진은 넣지 말고 '그림 자리'로만 두세요. 제가 파일을 열어 '그림 넣기' 창에서 고화질 사진을 넣어요.
  교과서 사진은 몇 쪽의 무슨 사진인지, 교과서에 없지만 있으면 좋은 사진은 위키미디어 공용·위키백과 검색어(한국어·영어)를 적어 주세요.

■ 만들 때 지킬 것
- 교과서 내용과 순서를 따르고, 교과서에 없는 내용은 발표자 노트에 (보충)이라고 적어 주세요.
- 한 장에 핵심 하나. 화면 글은 짧게, 자세한 설명은 발표자 노트로.
- 장마다 화면의 주인공을 크게. 같은 배치가 2장 넘게 이어지지 않게, 제목이 늘 같은 자리에 있지 않게.
- 모션은 화려하게, 말하는 순서대로 하나씩. 5~7장마다 학생 참여 장(퀴즈, 뒤집기 카드, 가리개, 그림 위 점).
- 지도·연표·도식은 직접 다시 그려 움직이게.
- 엔진 두 구역은 코드로 복사만 하고 한 글자도 바꾸지 마세요. 디자인과 슬라이드는 백지에서 한 장씩 새로 쓰세요.
‘화면’ 줄은 남겨 두세요

‘교실 TV’나 ‘빔프로젝터’라고만 쓰면 AI가 전자칠판(화면을 직접 만지는 수업)용으로 이해할 때가 있어요. 노트북을 연결해서 띄우면 그대로 두고, 강당이나 태블릿이면 괄호 안의 경우로 바꿔 써요.

2단계

고르고 답하기

AI가 단계마다 멈추고 물어봐요. 같은 대화에 짧게 답하면 돼요.

  1. 디자인 추천이 나오면 → “추천대로 해 주세요” 또는 “2번으로”
  2. 구성 계획과 시안이 나오면 → 시안 파일을 열어 →로 넘겨 움직임까지 봐요. 고칠 곳이 있으면 “5번은 빼 주세요”, “퀴즈를 하나 더”, “제목을 더 크게”처럼 말하고, 마음에 들면 → “좋아요. 만들어 줘”
  3. 전체 파일과 그림 자리 목록이 나오면 → HTML 파일을 내려받아요. 만드는 데 몇 분 걸릴 수 있어요.
디자인은 시안에서 눈으로 골라요

글로만 보면 고르기 어려워요. 시안이 마음에 안 들면 “1안으로도 시안 보여 줘”라고 해서 비교해 보세요. 여기서 디자인을 정해 두면 전체 슬라이드도 같은 수준으로 나와요.

3단계

그림 넣기

받은 파일을 크롬이나 엣지로 열면 아래에 “그림 자리 ○곳이 비어 있어요 · 그림 넣기”가 떠요. 누르면 그림 넣기 창이 열려요. 나중에는 메뉴 → 그림 넣기, 또는 I로 열어요.

  • 교과서 사진: 창에 적힌 쪽수의 고화질 그림 파일을 칸에 끌어다 놓거나, 칸을 눌러 골라요.
  • 보충 사진: 칸 옆의 위키미디어 공용·위키백과 버튼을 누르면 검색 결과가 열려요. 마음에 드는 사진을 내려받아 칸에 끌어다 놓아요.
  • 사진은 그림 상자에 맞게 줄여 파일 안에 들어가요. 고화질 원본을 넣어도 괜찮아요.
  • 다 넣으면 창의 저장이나 Ctrl+S. 크롬·엣지는 파일에 바로 저장되고, 다른 브라우저는 새 파일로 내려받아져요.
사진 쓰기 약속

교과서 사진은 우리 수업 안에서만 써요. 위키미디어 사진은 사진 페이지에서 라이선스(퍼블릭 도메인·CC)를 확인하고, 출처를 발표자 노트에 적어요. 사진을 넣은 파일은 인터넷에 올리지 않아요.

고칠 때

열어 보고 고치기

바꾸고 싶은 곳이 있으면 같은 대화에 보내요. 글자 몇 개는 편집 모드(Shift+E)에서 직접 고치는 편이 빨라요. 사진을 넣은 뒤에 AI에게 고친 파일을 받으면 사진은 다시 넣어야 하니, 말로 고치기는 사진을 넣기 전에 끝내요.

고치기 글
열어 보니 이런 점을 고치고 싶어요: [고칠 점]
비슷해 보이는 장: [예: 7~9번이 다 '제목 + 목록'이에요. 배치를 서로 다르게]
글자가 넘치거나 가려진 곳: [예: 12번 아래쪽 글자가 잘려요]
그림 자리를 더 만들어 주세요: [예: 15번에 신해혁명 당시 우창 사진]
엔진 구역은 그대로 두고, 작성 안내의 '다 만든 뒤' 확인을 다시 한 다음 고친 파일을 주세요.

태블릿

태블릿에서 열기

갤럭시 탭 (안드로이드)

‘내 파일’에서 HTML 파일을 누르고 크롬이나 삼성 인터넷으로 열어요.

아이패드

‘파일’ 앱 미리보기로 열면 넘김·필기 같은 기능이 동작하지 않을 수 있어요. 파일을 웹 주소로 올려 사파리로 열거나, 컴퓨터에서 여는 편이 확실해요.

  • 가로로 놓고 써요. 화면을 탭하면 다음 장, 좌우로 밀면 앞뒤로 넘어가요.
  • 필통의 펜으로 손가락이나 펜슬로 필기해요. 펜슬은 누르는 힘에 따라 굵기가 바뀌어요.
  • 전체 화면에서는 화면 가장자리를 탭하면 필통과 메뉴가 나오고, 3초 뒤 다시 숨어요.
  • 편집 모드에서 글자는 두 번 탭으로 고치고, 슬라이드 순서는 썸네일의 손잡이를 끌어 바꿔요.
  • 태블릿에서 저장하면 원래 파일을 덮어쓰지 않고 새 파일로 내려받아져요.

내 수업 게임 만들기

  1. 바탕화면에 vibecoding 폴더를 만들어요. 이름은 영어로 해요. AI와 프로그램이 한글 폴더 이름을 잘못 읽을 때가 있어요.
  2. 앱에서 그 폴더를 연결해요. 방법은 아래에 있어요.
  3. 글을 붙여 넣고 AI의 질문에 답한 뒤 “좋아요”라고 보내요. 파일을 만들어도 되냐고 물으면 ‘허용’을 눌러요.
  4. 폴더에 생긴 HTML 파일을 더블클릭하면 게임이 열려요.

만들기 전에 저를 인터뷰해 주세요.
· 질문은 한 번에 하나씩, 5개 안팎으로 해 주세요
· 물어볼 게 없으면 건너뛰어도 되고, 꼭 필요하면 더 물어봐도 돼요
· 다 들으면 만들 내용을 3줄로 정리해 보여 주고, 제가 “좋아요”라고 하면 만들어 주세요
B · 방탈출 퀴즈 (학생이 혼자 풀기)
‘vibecoding’ 폴더에 수업용 게임을 만들어 주세요.
· 게임: 학생이 혼자 푸는 방탈출 퀴즈. 문제를 3개 맞힐 때마다 문의 자물쇠가 하나씩 열리고, 9문제를 다 풀면 문이 열려요
· 문제: [중2 역사 ‘제1차세계대전’]의 핵심 용어 8개로 ‘뜻을 보고 용어 고르기’ 8문제 + 마지막 복습 1문제(용어를 보고 뜻 고르기)
· 보기는 4개, 틀린 보기는 흐리게 하고 남은 보기에서 다시 고르게
· 화면: 왼쪽은 문제와 9칸 진행 막대, 오른쪽은 자물쇠 3개가 달린 문
· 문이 열리면 축하 효과와 ‘다시 도전’ 버튼, 할 때마다 문제와 보기 순서 섞기
· 학생이 각자 자기 기기로 풀게, 글자와 버튼은 크게
· 컴퓨터·태블릿·휴대폰 모두 되게: 화면 크기에 맞춰 바뀌는 반응형, 마우스·터치 모두
· 파일 하나로, 더블클릭하면 열리게

· 질문은 한 번에 하나씩, 5개 안팎으로 해 주세요
· 물어볼 게 없으면 건너뛰어도 되고, 꼭 필요하면 더 물어봐도 돼요
· 다 들으면 만들 내용을 3줄로 정리해 보여 주고, 제가 “좋아요”라고 하면 만들어 주세요
‘반응형’ 한 줄을 넣으면 어디서나 잘 열려요

AI는 보통 컴퓨터 화면을 기준으로 만들어요. “컴퓨터·태블릿·휴대폰 모두 되게: 화면 크기에 맞춰 바뀌는 반응형, 마우스·터치 모두”라고 써 두면, 학생이 휴대폰이나 태블릿으로 열어도 글자와 버튼이 잘리지 않고 손가락으로 눌러져요. 반응형은 화면 크기에 맞춰 배치가 저절로 바뀐다는 뜻이에요. 위 A·B 글과 아래 기획 글에는 이미 들어 있어요. 내가 쓴 글에도 이 줄을 붙여 보세요.

끝의 인터뷰 부분은 지우지 마세요

AI가 바로 만들지 않고, 먼저 한 번에 하나씩 물어봐요. 짧게 답해도 되고, 물어볼 게 없으면 바로 정리해 줘요. 3줄 정리가 마음에 들면 “좋아요”라고 보내요.

B의 문제 수를 줄이려면 ‘9문제’와 ‘3개 맞힐 때마다’를 함께 바꿔요(예: 6문제, 2개마다). 다 만든 뒤에는 “색을 더 밝게”, “효과를 더 화려하게”, “문제를 3개 더”처럼 한마디씩 더 보내 고쳐요. 방탈출처럼 학생이 각자 푸는 게임은 아래 ‘주소로 나눠 주기’로 학생 기기에 보내고, 휴대폰으로도 한 번 열어 확인해요.

3 · 나눠 주기

학생에게 주소로 나눠 주기

만든 게임을 인터넷 주소로 올리면(배포) 학생이 각자 기기에서 열 수 있어요. Vercel이라는 서비스를 무료로 써요.

처음 한 번: 무료 가입

vercel.com → Sign Up(가입) → Hobby(개인이 쓰는 무료 요금제) → 이메일(또는 GitHub 계정)로 가입 → 메일로 온 확인 코드나 링크로 인증하면 끝이에요. 화면은 영어이고, 버튼 이름은 조금씩 바뀔 수 있어요.

방법 1 · 끌어다 놓기

  1. 로그인한 채로 주소창에 vercel.com/drop
  2. vibecoding 폴더를 화면에 끌어다 놓기
  3. 첫 화면이 될 파일 고르기 (게임 파일 이름이 index.html이면 건너뛰어요)
  4. 나온 주소 복사해 두기

설치할 것도, 코드도 없어서 가장 쉬워요.

방법 2 · AI에게 맡기기

게임을 만든 Code·Codex 대화에 이어서 아래 글을 보내요. 처음에는 Vercel 로그인 승인 창이 떠요.

AI가 필요한 프로그램을 설치해도 되냐고 물을 수 있어요. 학교 컴퓨터에서 설치가 막히면 방법 1로 해요.

배포 프롬프트 (방법 2)
‘vibecoding’ 폴더의 게임을 Vercel에 배포해 주세요.
· 게임 파일 이름은 index.html로 해 주세요
· 저는 처음이에요. 제가 할 일을 하나씩 알려 주세요
· 다 되면 학생에게 줄 주소를 알려 주세요
  • 링크로: 주소를 복사해 학급 게시판·클래스룸·메신저에 붙여 넣어요.
  • QR 코드로: 크롬 메뉴(⋮) → 공유 → QR 코드 만들기. 메뉴 이름은 크롬 버전에 따라 조금 달라요. AI에게 “이 주소 QR 코드 만들어 줘”라고 해도 돼요.
  • 고친 뒤 다시: AI에게 “고친 걸 다시 배포해 줘”. Drop은 로그인하고 같은 프로젝트에 다시 끌어다 놓아요. 새로 끌어다 놓으면 주소가 바뀔 수 있어요.
개인정보는 넣지 마세요

주소는 누구나 열 수 있어요. 학생 이름·사진 같은 개인정보는 게임에 넣지 않아요.

4 · 그림이 있는 게임

그림과 이야기가 있는 게임 만들기

그림·이야기·여러 단계가 있는 큰 게임도 방법은 같아요. 바로 만들어 달라고 하지 말고 기획서부터 함께 만들어요. 예: 독도 타임 패트롤 (중학생, 약 40분, 8단계 탐험)

  1. 기획 부탁계획부터 세워 달라고 해요
  2. 기획 다듬기규칙·화면·디자인·게임 방법을 고쳐요
  3. 그림 만들기그림 프롬프트를 받아 ChatGPT로 그려요
  4. 만들고 검토해 보고 고칠 점을 모아 말해요

① 기획 부탁하기

Code(Claude)나 Codex(ChatGPT)에서 vibecoding 폴더를 연결하고 보내요.

기획 프롬프트
[독도의 역사와 근거] 내용으로 [8단계 탐험] 형태의 게임을 만들고 싶어요. 만들기 전에 계획(기획서)부터 세워 주세요.
· 넣을 것: 대상·목표·기기·플레이 시간, 줄거리, 단계 구성, 규칙과 점수, 화면 구성, 필요한 그림
· 컴퓨터·태블릿·휴대폰 모두 되게: 화면 크기에 맞춰 바뀌는 반응형, 마우스·터치 모두
· 기획서는 ‘vibecoding’ 폴더에 game-plan.md로 저장해 주세요
· 궁금한 점은 한 번에 하나씩 물어봐 주세요

기획서가 파일로 남으면, 나중에 고칠 때도 AI가 이 기준을 따라요.

② 기획 다듬기

기획서에서 이 네 가지를 꼭 확인하고, 마음에 들 때까지 고쳐요.

  • 규칙: 틀리면 어떻게 되나요? (예: 게임 오버 없이, 정답 대신 단서가 있는 곳을 알려 주기)
  • 화면(UI/UX): 학생이 어떤 기기로 하나요? 컴퓨터·태블릿·휴대폰 어디서나 한 화면에 들어가나요? (예: 크롬북에서 스크롤 없이, 누르는 곳은 크게)
  • 디자인: 어떤 분위기, 어떤 그림체인가요? (예: 웹툰 그림체, 장소마다 다른 배경)
  • 게임 방법: 설명을 먼저 하나요, 해 보면서 알게 하나요? (예: 먼저 겪고 나중에 알게 하기)
고칠 때는 이렇게

“기획서의 [규칙]을 [틀리면 힌트 주기]로 바꿔 줘”처럼 기획서의 어느 부분을 어떻게 바꿀지 말해요.

③ 그림 만들기

Code·Codex에게 그림 프롬프트를 받아 ChatGPT에서 그려요.

그림 프롬프트 요청
game-plan.md를 보고, 게임에 필요한 그림 목록과 ChatGPT에 붙여 넣을 그림 프롬프트를 써 주세요.
· 그림마다 파일 이름, 들어갈 화면, 비율(배경 16:9, 캐릭터 1:1 투명 배경)을 적어 주세요
· 그림 안에는 글자를 넣지 않게 해 주세요
· 배경은 아래쪽을 비워 대사창 자리를 남겨 주세요
· 캐릭터는 기준 그림을 먼저 그리고, 다른 그림은 그 그림을 첨부해 같은 모습으로 그리게 해 주세요
· 지도나 사료처럼 정확해야 하는 것은 그림 대신 코드로 그려 주세요
· 목록은 ‘vibecoding’ 폴더에 image-prompts.md로 저장해 주세요
  1. ChatGPT에 그림 프롬프트를 하나씩 붙여 넣어 그려요. 캐릭터 기준 그림부터, 같은 대화에서 이어서 그리면 그림체가 같아요.
  2. 알려 준 파일 이름으로 저장해 vibecoding 폴더 안 images 폴더에 넣어요.
  3. Code·Codex에 “그림 넣었어. 게임에 넣어 줘”라고 보내요.

다 그린 뒤에는 글자 낙서, 이상한 손가락, 사실과 다른 모습이 없는지 확인해요. 교과서·뉴스 사진처럼 저작권이 있는 그림은 넣지 않아요.

④ 만들고 검토하기

“기획서대로 만들어 줘”라고 보내고, 다 되면 학생 기기로 처음부터 끝까지 직접 해 봐요. AI에게도 검토를 시켜요.

검토 프롬프트
만든 게임을 학생 입장에서 처음부터 끝까지 해 보고, 고칠 점 5가지를 찾아 주세요.
· 컴퓨터·태블릿·휴대폰에서 다 잘 보이고, 손가락으로도 잘 눌리나요?
· 글자와 버튼이 충분히 큰가요?
· 틀렸을 때 막히지 않고 이어지나요?
· 한 판에 걸리는 시간이 [40분]에 맞나요?
고칠 점은 번호를 붙여 보여 주세요. 고칠 번호는 제가 고를게요.

고칠 번호를 골라 “1, 2번 고쳐 줘”라고 보내요. 규칙처럼 큰 것이 바뀌면 기획서부터 고쳐 달라고 해요(② 다시). 내용이 교과서와 맞는지는 꼭 직접 확인해요. AI도 틀려요. 다 되면 위의 ‘주소로 나눠 주기’로 학생에게 보내요.

도움말

자주 묻는 것

ChatGPT 같은 다른 AI에서도 되나요?

프롬프트와 기능 파일은 특정 AI 전용이 아니에요. PDF를 읽고, 코드로 파일을 다루고, 완성된 파일을 내려받게 해 줄 수 있는 AI라면 같은 방법으로 쓸 수 있어요. ChatGPT에서는 코드 실행 기능이 이 일을 해요. 요금제마다 파일 올리기나 코드 실행에 제한이 다를 수 있으니 한 번 해 보고 쓰세요. 받은 파일을 열었을 때 필통과 메뉴 버튼이 보이고 →를 누를 때 내용이 차례로 나오면 잘 된 거예요. ChatGPT에서도 이 방법으로 잘 되는 것을 확인했어요.

Claude의 Code 탭에서 Git을 설치하라고 나와요

입력창에서 vibecoding 폴더를 연결하고 Cowork(맡기기)로 같은 게임 글을 보내도 게임 파일이 만들어져요.

게임 파일이 어디 생겼는지 모르겠어요

바탕화면의 vibecoding 폴더를 열어 보세요. 그래도 없으면 같은 대화에 “만든 파일 이름과 위치를 알려 줘”라고 보내요.

필통이나 넘김 화살표가 안 보여요

미리보기 앱으로 열었을 수 있어요. 크롬이나 엣지로 열어 보세요. 그래도 안 되면 엔진 구역이 바뀌었을 수 있으니, 고치기 프롬프트에 “기능 파일의 엔진 구역을 그대로 다시 복사해 줘”라고 적어 보내요.

글자가 상자 밖으로 넘쳐요

몇 번 장의 어느 글자인지 고치기 프롬프트의 ‘글자가 넘치거나 가려진 곳’에 적어 보내요. AI가 작성 안내에 있는 확인을 다시 하고 고쳐 줘요.

슬라이드가 다 비슷하게 생겼어요

AI가 한 가지 배치를 되풀이하면 생겨요. 시안 단계에서 콘셉트를 다시 고르거나, 고치기 프롬프트의 ‘비슷해 보이는 장’에 번호를 적어 “장마다 주인공을 정하고 배치를 서로 다르게”라고 보내요. 기능 파일의 회색 장은 기능 시연이라 그 모양을 따라 하면 안 된다는 것도 함께 적어 주세요.

움직임이 너무 많아서 정신없어요

메뉴 → 설정 → 모션 강도에서 ‘보통’이나 ‘차분’을 고르면 바로 줄어들어요. 덱마다 따로 기억해요.

어떤 사진을 써도 되나요?

직접 찍었거나 사용 권한이 있는 사진을 쓰세요. 교과서 그림은 우리 수업 안에서만 쓰고, 파일을 인터넷에 올리거나 나눌 때는 빼 주세요. 위키미디어 공용 사진은 사진 페이지에서 라이선스(퍼블릭 도메인·CC)를 확인하고 출처를 발표자 노트에 적어요.

그림 넣기 창에서 넣은 사진이 다시 열면 없어요

창의 ‘저장’이나 Ctrl+S를 해야 파일에 남아요. 크롬·엣지는 처음 저장할 때 저장할 파일을 고르고, 다른 브라우저는 사진이 들어간 새 파일로 내려받아져요. 그 새 파일을 열어 쓰세요.

필기는 어디에 저장되나요?

필기와 설정은 그 컴퓨터의 브라우저에 슬라이드별로 저장돼요. 다른 컴퓨터로 파일만 옮기면 필기는 따라가지 않아요.
