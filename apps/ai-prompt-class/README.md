# AI 프롬프트 특강 · 학생 페이지와 결과판

중2 프롬프트 특강 덱(`decks/2026-12-24-ai-prompt-class/`)과 함께 쓰는 **구글 앱스 스크립트 웹 앱**이에요.
QR 하나로 학생 페이지가 열리고, 학생이 올린 Before·After가 큰 화면 결과판에 모이며, 투표까지 해요.

| 파일 | 하는 일 |
|---|---|
| `Code.gs` | 서버: 입장 코드 확인, 결과 저장(구글 시트·드라이브), 투표, 교사 조작 |
| `student.html` | 학생 페이지: 입장 → 추천 조합·재료 고르기 → 복사 → 제미나이 → Before·After 올리기 → 우리 반 투표 → 반 대표 대결 |
| `board.html` | 결과판(큰 화면): 반 탭, Before → After 카드, 실시간 표, 반 대표 대결, 교사 조작 단추 |
| `appsscript.json` | 시간대(서울)와 웹 앱 설정 |
| `dev/` | 확인용(배포하지 않아요): 가짜 앱스 스크립트 위에서 두 페이지를 브라우저로 시험해요 |

## 배포하기 (선생님 개인 Gmail, 처음 한 번 약 10분)

학교 계정은 ‘모든 사용자’ 공개가 막힐 수 있어서 **개인 Gmail**로 배포해요.

1. 개인 Gmail로 로그인한 크롬에서 [script.google.com](https://script.google.com) → **새 프로젝트**. 이름을 `AI 프롬프트 특강`으로 바꿔요.
   (구글 시트를 먼저 만들고 **확장 프로그램 → Apps Script**로 열어도 돼요. 그러면 결과도 그 시트에 쌓여요. 이 경우 그 시트를 지우면 코드도 같이 지워지니 지우지 마세요.)
2. 처음 보이는 `Code.gs`의 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣어요.
3. 왼쪽 **파일 +** → **HTML** → 이름 `student` → 이 폴더의 `student.html` 내용을 붙여 넣어요. 같은 방법으로 `board`도 만들어요(`board.html`).
4. 왼쪽 **프로젝트 설정(톱니바퀴)** → ‘편집기에서 appsscript.json 매니페스트 파일 표시’를 켜고, `appsscript.json` 내용을 붙여 넣어요.
5. 위쪽 함수 목록에서 **setup**을 고르고 **실행** → 권한 검토 → 내 계정 → ‘고급’ → ‘(안전하지 않음)으로 이동’ → **허용**.
   직접 만든 스크립트라 이렇게 물어요. 시트와 드라이브에 결과를 저장하는 권한이에요.
6. 아래 **실행 로그**에 입장 코드, 교사 키, 결과 시트 주소가 나와요.
7. 오른쪽 위 **배포** → **새 배포** → 유형 **웹 앱** → 실행 계정 **나**, 액세스 권한 **모든 사용자** → **배포** → **웹 앱 URL**을 복사해요.

| 주소 | 누가 | 쓰는 곳 |
|---|---|---|
| `웹 앱 URL` | 학생 | 슬라이드의 QR |
| `웹 앱 URL?p=board&k=교사키` | 선생님 | 큰 화면 결과판(교사 단추가 보여요). 교사 키는 학생에게 보여 주지 않아요 |
| `웹 앱 URL?p=board&k=교사키&m=2` | 선생님 | 결과판을 열면서 미션 2를 열어요 |

웹 앱 URL을 Claude에게 알려 주면 슬라이드의 QR과 결과판 단추에 넣어요.

**코드를 고친 뒤에는** 배포 → 배포 관리 → 연필 → 버전 ‘새 버전’ → 배포. 이렇게 하면 주소가 그대로예요(새 배포를 만들면 주소가 바뀌어요).

## 수업 중에

- 결과판 아래쪽 흐린 **교사 단추**: `대기` · `미션 1~6` · `반 대표 대결` · `새 입장 코드`. 미션을 열면 학생 화면이 몇 초 안에 저절로 바뀌어요.
- 결과판 카드를 누르면 Before와 After를 크게 보여요. 장난 제출은 **숨기기**(학생 화면과 표에서 빠져요).
- 투표는 학생이 After를 올리면 바로 열려요(자기 반 안에서, 자기 작품 빼고, 바꿀 수 있어요). 따로 투표 시간을 잡지 않아도 돼요.
- 마무리에 `반 대표 대결` → 반마다 오늘 표를 가장 많이 받은 작품 하나씩, 150명 모두 투표해요.

## 수업 뒤에

- 편집기에서 **resetAll** 실행 → 제출·투표·그림을 모두 지우고 새 입장 코드를 만들어요(되돌릴 수 없어요).
- 드라이브의 `AI 프롬프트 특강 그림` 폴더와 휴지통도 비워 주세요. 이름은 받지 않지만 반·번호가 남아 있어요.

## 강의 전 리허설 (꼭 한 번)

실제 갤럭시탭 여러 대로 확인해야 하는 것들이에요.

- [ ] QR을 찍으면 학생 페이지가 열리고, 입장 코드로 들어가진다
- [ ] ‘복사하기’가 되는지, 안 되면 ‘길게 눌러 복사’ 안내대로 복사된다
- [ ] ‘제미나이 열기’ → 학교 계정 제미나이가 열린다 → 다시 학생 페이지로 돌아오면 하던 곳 그대로다
- [ ] 제미나이 그림을 저장(또는 캡처)해서 ‘사진 고르기’로 올린다
- [ ] 글 답을 길게 눌러 복사해서 붙여 넣고 올린다
- [ ] 결과판에 카드가 몇 초 안에 튀어나오고, 투표하면 표 막대가 올라간다
- [ ] 여러 대가 한꺼번에 올려도 모두 들어간다 (느리면 ‘잠깐 기다리는 중’ 안내 뒤 자동으로 다시 보내요)

## 만든 방식 (고칠 때 참고)

- 학생 페이지는 구형 기기 때문에 ES5 문법만 쓰고, 최신 CSS(`color-mix`, `:is`, flex `gap`)를 쓰지 않아요.
- 결과는 시트 `m{미션}_{반}`에 줄을 **추가만** 하고(다시 올리면 마지막 줄이 이겨요), 투표도 `votes`에 추가만 해요(사람마다 마지막 표가 이겨요). 그래서 동시에 많이 올려도 잠금 없이 안전해요.
- 그림은 원본(긴 변 1280px)을 드라이브에, 작은 그림(320px)을 시트에 넣어요. 결과판과 투표 화면은 작은 그림만 받아서 빨라요.
- 학생·결과판은 몇 초마다 새 줄만 받아 와요(시트별 읽은 줄 수를 기억).
- 확인: `node apps/ai-prompt-class/dev/test.cjs <스크린샷 폴더> <사진.jpg>` (사진 옆에 `<사진.jpg>.thumb` 작은 그림 data URL 파일이 있으면 씀)
