# HTMLzip

모션 그래픽이 들어간 HTML 슬라이드 모음입니다.
**HTML 파일 하나만 열면** 움직이는 슬라이드와 발표·필기·편집 도구를 모두 쓸 수 있습니다.
기능은 모든 덱이 같고, 디자인은 덱마다 자유롭게 만듭니다.

## 모든 덱에 들어가는 기능

| 분류 | 기능 |
|---|---|
| 모션 | 전환, 등장, 강조, 퇴장, 숫자·도식, 배경 움직임, 상호작용(뒤집기 카드·퀴즈·가리개), 축하 효과 |
| 이동 | 이전/다음, 단계별 등장, 목차, 진행 바, 페이지 번호, 클릭·스와이프 |
| 필기 | 손, 펜, 형광펜, 지우개(획·부분), 레이저, 색, 되돌리기, 이 장 지우기, 전체 지우기 |
| 모드 | 슬라이드, 칠판, 보기 모드(기본/발표자) |
| 전체 화면 | 누르면 도구가 숨고 슬라이드와 페이지 번호만 보임. 툴바는 화면 가장자리에서 잠깐 불러옴 |
| 편집 | 모든 요소(텍스트·이미지·도형) 이동·크기·스타일·모션 편집, 슬라이드 순서 변경·추가·복제·삭제, 저장, 점검 |
| 발표 보조 | 타이머, 툴바 위치·접기, 단축키 도움말 |
| 설정 | 테마, 모션 강도(끄기/차분/기본/화려), 필기 기본값 등 |

자세한 명세와 등급(필수/권장/선택)은 [docs/PRINCIPLES.md](docs/PRINCIPLES.md)에 있습니다.

## 문서

- [docs/PRINCIPLES.md](docs/PRINCIPLES.md): 제작 원칙과 기능 명세. 이 저장소의 기준 문서입니다.
- [CLAUDE.md](CLAUDE.md): Claude가 이 저장소에서 작업할 때 자동으로 읽는 지침입니다. 위 원칙을 불러와 따릅니다.

## 구조

```
docs/PRINCIPLES.md   제작 원칙
engine/              모든 덱이 함께 쓰는 기능 코드 (디자인 없음)
tools/               엔진을 덱에 넣는 도구 (node tools/sync-engine.js)
themes/              다시 쓰고 싶은 디자인 모음 (선택, 아직 없음)
decks/               완성된 슬라이드 (각 파일에 엔진이 들어 있음)
wip/                 원칙 이전에 만든 작업본 (참고용)
```

엔진은 `engine/`에서만 고치고, `node tools/sync-engine.js`로 모든 덱의 엔진 구역을 바꿔 넣습니다.

## 보는 법

`decks/` 안의 HTML 파일(폴더형 덱은 `index.html`)을 브라우저로 열면 됩니다. 덱 안에서 `?` 키를 누르면 단축키 목록이 나옵니다.
