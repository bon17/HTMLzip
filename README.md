# HTMLzip

모션 그래픽이 들어간 HTML 슬라이드 모음입니다.
**HTML 파일 하나만 열면** 움직이는 슬라이드와 발표·필기·편집 도구를 모두 쓸 수 있습니다.
기능은 모든 덱이 같고, 디자인은 덱마다 자유롭게 만듭니다.

| 이동 | 이전/다음, 단계별 등장, 목차, 진행 표시, 클릭·스와이프, 번호로 이동 |

## 보는 법

`decks/` 안의 HTML 파일을 크롬이나 엣지로 열면 됩니다. 필기 도구는 왼쪽 아래 필통에, 나머지 기능은 왼쪽 위 메뉴 버튼에 있습니다. 덱 안에서 `?` 키를 누르면 단축키 목록이 나옵니다.

- `F` 전체 화면 · `P` 펜 · `E` 지우개 · `B` 칠판 · `T` 타이머 · `R` 랜덤 뽑기 · `.`/`,` 화면 가리기 · `S` 발표자 창 · `M` 효과음 · `G` 축하 · `O` 목차
- `Shift + E` 편집 모드 · `Ctrl + S` 저장

## 구조

```
docs/PRINCIPLES.md      제작 원칙 (기준 문서)
engine/engine.css       엔진 스타일 (디자인 없음)
engine/engine.js        엔진 기능
tools/sync-engine.mjs   엔진을 덱 파일에 넣고 갱신하는 도구
decks/                  완성된 슬라이드 (각 파일에 엔진이 들어 있음)
kits/                   연수 때 나눠 주는 안내 파일 (덱이 아니라서 엔진 갱신 대상이 아님)
themes/                 다시 쓰고 싶은 디자인 모음 (선택, 아직 없음)
wip/                    원칙이 생기기 전의 작업본 (옮기는 중)
```

## 엔진을 고쳤을 때

`engine/`만 고친 다음 아래 명령으로 모든 덱에 넣습니다. Node.js가 있으면 됩니다.

```bash
node tools/sync-engine.mjs
```

덱이 최신 엔진인지 확인만 하려면 `--check`를 붙입니다. 엔진 구역에 `data-engine-lock`을 붙인 덱은 지금 엔진 그대로 두고 건너뜁니다(시범 덱 2개와 교사 연수 덱은 v2.3으로 고정).

```bash
node tools/sync-engine.mjs --check
```

## 새 세션에서 이어서 작업하기

- 덱은 파일 하나에 엔진까지 다 들어 있어서 서로 **독립적**입니다. 새 덱을 만들거나 엔진을 고쳐도 이미 만든 덱은 그대로 동작합니다.
- Claude는 새 세션마다 [CLAUDE.md](CLAUDE.md)와 원칙을 자동으로 읽고, 같은 엔진·같은 규칙으로 작업합니다.
- 원칙과 엔진의 기준은 **`main` 브랜치**입니다. Claude는 세션을 시작하면 따로 말하지 않아도 `main`을 먼저 확인해 최신 원칙·엔진으로 맞추고, 원칙이나 엔진을 바꾸면 `main`에 합칠지 물어봅니다([CLAUDE.md](CLAUDE.md)의 ‘항상 main 기준’).
- 새 세션은 저장소의 **기본 브랜치**에서 시작하므로, GitHub 저장소 설정에서 기본 브랜치를 `main`으로 해 두세요.
